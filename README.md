# Enhancing Efficiency of Wind Farm Energy using Digital Twin Technology

![IEEE](https://img.shields.io/badge/IEEE-Published-blue)

**Authors:** Jesline Daniel, Sugam Bhardwaj, Harshit Ravindra Kulkarni, Habibur Rahman, Sanchi Mahajan, Shikhar Agrawal

**Conference:** 15th ICCCNT IEEE Conference, IIT Mandi, June 24-28, 2024

**DOI:** 10.1109/ICCCNT61001.2024.10724122

## Abstract Summary

This paper presents a digital twin-based framework for wind farm monitoring and maintenance using real-time sensor data. The virtual replica supports performance evaluation, predictive maintenance, and fault detection to improve reliability, reduce downtime, and optimize energy output.

The approach combines time-series forecasting and analytics to help operators identify underperforming turbines, anticipate failures, and manage maintenance more efficiently.

## Key Topics

- Predictive Maintenance

- XTGN
- Fault Detection
